{{appName}} lets you create AI agents, give each one its own instructions and model, and run them from your phone. Everything stays on your device, and you use your own Anthropic API key.

What it does

  • Build agents

    Give each agent a name, instructions, a Claude model and an effort level. Start from a template or from scratch.

  • Run and review

    Chat with any agent, keep separate conversations, and pause agents you're not using.

  • See your usage

    Every reply shows its token counts and an estimated cost, based on Anthropic's published prices.

  • Private by design

    No account, no analytics, no ads, no tracking. Your agents and conversations are stored only on your device.

  • Your data, your control

    Export everything to a file or delete it all from the Privacy center at any time.

  • Accessible

    Built for screen readers, large text, keyboard use on the web, and checked colour contrast in light and dark themes.
